# Working docs

Planning and design notes that are genuinely in flight live here. When a plan's work ships,
the plan moves to [`archive/`](archive/README.md) — stamped with what actioned it and with
references repointed — so this folder only ever describes the present. Dead plans are not
kept here.

Currently live:

- [`remaining-items.md`](remaining-items.md) — small open items extracted from otherwise
  actioned plans.
